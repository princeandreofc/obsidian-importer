## Pipeline (por faixa)

1. **Brief** (abaixo) → gerar no Suno (2–4 variações; guardar seed/link).
2. **Seleção** — escolher a variação; exportar WAV + stems se disponível.
3. **Logic/FL** — arranjo final, voz, mix; bounce 24-bit/48k.
4. **Master** — loudness alvo streaming (−14 LUFS int.), true peak ≤ −1 dBTP.
5. **Registro** — preencher a linha no catálogo + campos de direitos.
6. **Palco** — status `cleared-production` → entrar em `MASTERS` do player.

saturação de fita no master bus.
