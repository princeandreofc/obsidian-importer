## 5. Creative thesis

### 5.1 Love as signal

Love is represented as a signal only when it passes between bodies. The visual system therefore avoids hearts, halos and wellness clichés. It uses tension, resonance, return, orbit, memory and shared alignment.

The visitor never passively watches the symbol. Scroll, pointer, touch, keyboard, authorized music and optional microphone input alter the field. The work becomes most stable when separate particles form temporary connections.

### 5.2 The Resonance Rose

The Resonance Rose is not a fixed logo. It is a reproducible generative system with a recognizable silhouette.

Canonical construction:

- one circular water membrane;
- twelve harmonic petals;
- six crystalline axes;
- two counter-rotating orbital fields;
- one inward spiral representing memory and return;
- small human-scale particles that connect along the field;
- a warm core pulse surrounded by cool nocturnal light;
- slight asymmetry so the emblem feels alive rather than sacred or corporate.

The symbol may be rendered as:

- live WebGL geometry;
- flat SVG fallback;
- embossed vinyl label;
- water/ink macro film;
- 3D glass sculpture;
- particle constellation;
- VJ scene topology;
- social crop and motion loop;
- accessible CSS/DOM diagram.

## 6. 528 Hz: use, limits and visual research

### 6.1 Positioning

528 Hz is used as a cultural and spiritual association of love and as an artistic composition rule. It is **not** described as a healing frequency, a treatment or a scientifically established property of love.

Required public note in the About/Credits layer:

> “528 Hz is used in this artwork as a cultural and compositional reference. No medical or therapeutic claim is made.”

### 6.2 Scientifically grounded visual source

Faraday waves are real standing-wave phenomena. Their polygonal patterns depend on forcing, container geometry, liquid depth, viscosity, amplitude and boundary conditions. There is no single universal “528 Hz water shape.” The project should therefore simulate or art-direct a parameterized wave field, never label one ornamental image as scientific proof.

Use three evidence tiers:

| Tier | Source class | Allowed use | Required label |
| --- | --- | --- | --- |
| A | Peer-reviewed Faraday-wave research | Physics and geometry reference | `physics-reference` |
| B | Cymatics/Chladni demonstrations and visualizers | Motion/design exploration | `artistic-demonstration` |
| C | Masaru Emoto water-crystal imagery | Cultural/spiritual archive only | `unverified-cultural-reference` |

The Emoto archive presents selected crystals for music, words and “Love and Gratitude,” but does not provide a reproducible controlled protocol on the gallery page. The work may inspire six-fold frost geometry, but the original images must not be reproduced without permission and must never be presented as proof.

### 6.3 528-derived motion and sound tokens

Use the number as a quiet compositional spine rather than a constant audible sine wave:

```ts
export const SIGNAL_528 = {
  calibrationHz: 528,
  foldedHz: [66, 132, 264, 528],
  transitionMs: 528,
  breathMs: 5280,
  holdMs: 1056,
  normalized: 0.528,
} as const;
```

Audio rules:

- audio is opt-in and starts only after a user gesture;
- the 528 Hz calibration tone, if used, lasts no more than 528 ms and starts at or below `-24 dBFS`;
- longer beds use folded harmonics such as 66, 132 or 264 Hz, mixed musically;
- no binaural, therapeutic or nervous-system claims;
- no unauthorized masters, stems, samples or voice;
- provide mute, volume and captions/descriptive text.

### 7.1 The resulting visual DNA

The recurring grammar is:

1. **A single central object** with enough force to act as a cover.
2. **Humanity inside the machine**, not technology replacing the person.

## 12. Web game — RESONANCE SESSION

### P0: local connection

The current 30-second loop remains:

`CALIBRATE 0–5s → BUILD 5–18s → HOLD 18–26s → CAPTURE 26–30s`

States remain:

`UNSTABLE → LISTENING → RESONANT → REMEMBERED`

Verbs remain:

`TUNE → SHAPE → CAPTURE`

The new connection rule is simple: isolated particles create unstable energy; two or more aligned clusters create a visible bridge; sustained bridges increase resonance; the room remembers the final topology. There is no game over, leaderboard, account, username or PII.

The recorded clip is the trophy. It includes a short text card containing the campaign name, session seed and accessibility-safe colors, but no unauthorized music.

### P1: connected rooms, not part of the authorized P0 build

Only after separate approval, an ephemeral multiplayer layer may use WebSockets with a stateful edge room. It must transmit normalized control vectors, never microphone audio. Rooms use random IDs, no identity, no chat and short TTL. Cloudflare Durable Objects is the preferred architecture if this phase is approved because a single object can coordinate deterministic room state; it is not a P0 dependency.
